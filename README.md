# SaveOceanConcept(FEE)

Este é um projeto, que foi desenvolvido na disciplina de Programação Web Front End, que também se complementará com a idéia proposta na disciplina de Empreendedorismo.
Sobre o Projeto:
SaveOcean é uma landing page desenvolvida para uma organização fictícia dedicada à preservação dos oceanos e da vida marinha. O projeto foi criado com foco em design moderno, responsivo e acessível, utilizando apenas HTML e CSS puro.


🎯 Missão
Transformar tempo ocioso em tempo precioso, salvando a vida marinha de forma ostensiva, extensiva e principalmente intuitiva.
✨ Funcionalidades

Design Responsivo: Adaptável a diferentes tamanhos de tela
Degradê Oceânico: Transição visual do azul claro ao roxo profundo
Menu de Navegação: Links para diferentes seções do site
Cards Informativos: 4 seções destacando missão, comunidade, sustentabilidade e resultados

🆕 Funcionalidades e Tecnologias Implementadas
O projeto foi expandido com um sistema completo de gerenciamento de dados utilizando JavaScript puro e APIs nativas do navegador. Implementamos um painel administrativo (admin.html) que oferece um CRUD completo para cadastro de usuários, permitindo adicionar novos membros com nome e e-mail validado (incluindo verificação de formato e detecção de duplicatas). O sistema utiliza a Web Storage API (Local Storage) para persistência de dados em formato JSON, garantindo que as informações permaneçam armazenadas mesmo após o fechamento do navegador. A interface conta com funcionalidades avançadas como busca em tempo real por nome ou e-mail, exclusão individual de registros com confirmação, exclusão em massa de todos os dados, e botão para limpeza de campos do formulário. Toda a manipulação de elementos é realizada através da DOM API, criando e atualizando dinamicamente a lista de usuários exibida na tela. Cada registro é apresentado com data e hora de cadastro formatada em português brasileiro, nome completo e e-mail, além de um botão individual de exclusão. Adicionalmente, o formulário de condições da água (formulario-agua.html) coleta dados ambientais como localização, qualidade da água, temperatura, níveis de poluição e observações de vida marinha, armazenando todos os relatórios no Local Storage para futuras análises. O projeto não utiliza frameworks ou bibliotecas JavaScript externas além de Font Awesome para ícones, demonstrando o uso eficiente de tecnologias web fundamentais (HTML5, CSS3 e JavaScript Vanilla) para criar uma aplicação funcional e responsiva.
